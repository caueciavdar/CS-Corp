# Project overview

- Nome do repositório: CS Corp (CS-Corp); nome comercial público oficial: TBD.
- Objetivo: estabelecer o novo website da empresa.
- Website atual: https://www.conexionservicesfl.com/
- Contexto informado pelo usuário: site atual basicamente composto por uma landing page.
- Novo website: experiência completa, profissional, moderna, limpa, fácil de usar e navegar, preparada para crescimento e múltiplas páginas.
- Stack: React, TypeScript, HTML5, CSS, Vite e npm. Sem PHP.
- Princípios: simplicidade, reutilização, organização, responsividade, acessibilidade e documentação versionada como source of truth.
- Status: fundação técnica e visual inicial com tokens e primitives reutilizáveis; direção visual, paleta inicial, tipografia, idioma, CTA, navegação inicial e estrutura de alto nível da Home estão aprovados para orientar etapas futuras.
- Escopo atual: registrar decisões aprovadas e preparar o Design System. Sem construir a Home, Header ou Hero, sem criar conteúdo comercial inventado, backend, integrações ou deploy automático.
